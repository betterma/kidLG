# KidLG 策划案 v0.1

**定位：** 面向 3–8 岁幼儿的网页学习游戏，用「摸得到、听得到、拼得上」的交互，把字母、拼音、汉字、单词逐步练熟。

**核心玩法原型：** 缺口 + 散落块 → 拖拽吸附 → 发音反馈 → 撒花过关。

---

## 一、产品一句话

把认读变成拼图游戏：孩子拖一块「字形 / 音节」进对应缺口，系统发音确认，通过后再解锁下一关。

---

## 二、目标用户与使用场景

| 角色 | 诉求 |
|------|------|
| 幼儿（主用户） | 大按钮、强反馈、短关卡、少文字说明 |
| 家长 | 能看到进度、控制难度、放心无广告干扰 |
| 场景 | 手机 / 平板横竖屏均可；单次 5–15 分钟 |

**原则：** 一关只练一件事；失败不惩罚，只有重试与鼓励。

---

## 三、进阶路线（内容骨架）

按「感知 → 对应 → 组合 → 应用」排级，关卡地图按大世界解锁。

### Stage 0 · 引导世界（免登录可玩）

- 手指点一下会响、拖一下会跟手
- 1–2 关：任意形状塞进洞（圆形进圆洞），建立「拖进去 = 成功」心智模型

### Stage 1 · 英文字母（MVP 首发）

1. **单字母嵌合：** `a` 缺口 + 散落 `a` → 点击发音 → 拖近吸附 → 三连发音 + 撒花
2. **大小写配对：** `A` 洞配 `A`，旁有干扰项 `a` / `b`（可选难度）
3. **字母找朋友：** 听到 `/æ/` 或说 “apple 的开头”，点出 `A` / `a`
4. **字母串门：** 按顺序把 `a-b-c` 放进三格轨道（顺序拼）

### Stage 2 · 拼音

1. 单韵母 / 声母嵌合（同字母玩法）
2. 声母 + 韵母拼成音节（两块拼进双缺口）
3. 带声调：拖正确声调符号到音节上
4. 听音选音节（3 选 1）

### Stage 3 · 汉字

1. 独体字整字嵌合（「木」「日」）
2. 部件拼字（「木」+「木」→「林」）——仍是拖拽吸附，不是写字笔迹
3. 看图选字 / 听读选字
4. 简单词语两字并排嵌合（「大」+「小」）

### Stage 4 · 英文单词拼写

1. 看图 + 字母槽：`c_t` 拖入 `a`
2. 打乱字母重排成词（3–4 字母词起步）
3. 听词拼写（语音 → 拖字母）
4. 短句填空（后期）

### Stage 5 · 汉字词语 / 混合进阶

- 词语配对、反义词、量词搭配
- 「拼音 → 汉字」「字母词 → 图」跨轨复习关

**解锁规则建议：** 通关当前大关 80% + 当日连续成功 3 关 → 开下一世界；家长可手动解锁。

## 四、核心玩法模板（可复用引擎）

所有关卡尽量套同一套交互，只换素材与规则参数，保证开发可控、孩子学习成本低。

### 模板 A：嵌合拼图（Fit-in）—— 首发核心

1. **场景：** 墙 / 木板 / 沙坑上有字形凹陷
2. **地上：** 1–N 个可拖块（正确块 + 可选干扰块）
3. **按下：** 播放该块读音（或音效）
4. **拖动：** 块跟随手指，洞口可轻微高亮吸附区
5. **松手：** 距离 ≤ 阈值 → 磁吸对齐 + 成功音；否则弹回原位 + 轻提示
6. **成功：** 连续 3 次目标读音 + 撒花 / 贴纸 + 「下一关」

### 模板 B：听音点选（Tap-to-Match）

播放目标音 → 孩子点正确图 / 字（无拖拽，适合更小龄）

### 模板 C：多槽拼合（Multi-slot）

一个词 / 音节拆成多块，按顺序或任意正确槽位填入

### 模板 D：配对连线（后期）

左右两侧拖近配对（拼音–汉字、大小写）

> **MVP 只做模板 A + 极简模板 B；C / D 第二期。**

## 五、单关体验节奏（以 a / A 为例）

| 时间 | 体验 |
|------|------|
| 0–2s | 进入关：温和背景、缺口微光、块轻轻晃一下「点我」 |
| 点击块 | 清晰「a」人声（童声优先） |
| 拖近洞 | 洞口脉动；松手成功 → 咔哒贴合 |
| 成功 | 「a… a… a…」+ 粒子撒花 + 小星星进收集袋 |
| 出口 | 大按钮「再玩一次 / 下一关」；无复杂结算页 |

**失败设计：** 块弹回 + 洞口再闪一下；不扣星、不弹错脸。连续 2 次未中可出现半透明「幽灵轨迹」暗示方向（可关）。

## 六、趣味性与留存设计（克制版）

少儿产品忌花哨干扰学习，建议「反馈强、装饰弱」：

1. **收集：** 每关一颗字母星 / 汉字印章，集齐墙面展示
2. **场景换皮：** 同一玩法换「木墙、黑板、沙滩、积木桌」
3. **角色：** 固定一个安静吉祥物（例如小狐狸）只在成功时蹦一下，不抢操作
4. **短会话：** 推荐「今日 5 关」；打完给贴纸，避免刷关疲劳
5. **家长周报：** 本周练了哪些字母 / 字，正确率（可选）

**不做：** 排行榜对战、复杂剧情、强制看广告、连续失败惩罚。

## 七、信息架构（网页）

```
首页（世界地图）
 ├─ 英文字母世界（26 + 大小写变体关）
 ├─ 拼音世界
 ├─ 汉字世界
 ├─ 单词拼写世界
 └─ 词语世界

设置：音量 / 自动下一关 / 干扰项开关 / 家长锁
进度：见下方「进度策略」
```

首页用「路径地图」点亮节点，而不是菜单列表——更游戏感。

## 七-B、当前开发设定（已修订）

| 项 | 定案 |
|----|------|
| 站点托管 | **GitHub Pages** |
| 关卡 / 阶段 / 定价等配置数据 | **仓库内 JSON**（随 Pages 一起发布） |
| 音效、木墙等静态资源 | **仓库 `assets/`**，由 Pages 直接提供 |
| 孩子进度 | **见进度策略**（本机必有；激活后额外同步到 GitHub） |
| 腾讯云 / 云函数 / PostgreSQL | **本期不做**；支付发码、硬校验码等再接 |

### 进度策略（产品定案）

| 状态 | 本机浏览器 | GitHub |
|------|------------|--------|
| **未激活** | 读写进度（唯一存档） | 不同步 |
| **已激活** | 仍读写进度（主存档，离线也能玩） | **后台静默同步**一份，按激活码归档 |

孩子无感；失败不影响游玩。换设备输同一激活码后，可先拉 GitHub 存档再与本机合并。

> **技术注意：** 网页不能把「能写仓库的 GitHub Token」藏在前端（会被人拿走改你的库）。静默写入 GitHub 需经一层 **只含写权限的小中转**（如免费 Cloudflare Worker，或以后腾讯云函数），Token 只放在中转侧。MVP 可先完成本机读写 + 同步接口预留，中转后接。

> 激活码、进度文件若在 **公开仓库** 可被下载；进度文件建议用激活码的哈希做文件名，正式环境优先 **私有进度仓** 或迁数据库。

## 八、可实现性评估（网页技术）

| 模块 | 建议 | 难度 |
|------|------|------|
| 拖拽吸附 | Pointer Events + 碰撞距离判定 | 低 |
| 发音 | Web Audio / HTMLAudio；预加载短 wav/mp3 | 低 |
| 字形缺口 | SVG 路径或透明 PNG 遮罩；洞与块共用同一矢量 | 中 |
| 撒花 | Canvas / CSS 粒子，短时播放 | 低 |
| 进度 | localStorage | 低 |
| 配置数据 | 仓库 JSON + `fetch` | 低 |
| 多端触摸 | 以 touch 为主测；避免 hover 依赖 | 中 |
| 内容量 | 字母 26 关可程序化生成；汉字需内容表 | 中（内容） |

**高风险点：** 汉字「笔顺书写」——本期明确不做手写识别，只做「整字 / 部件拖拽」，可实现性最高。

**音频：** 字母 / 拼音可用 TTS 批量生成后人工抽检；核心字母建议录制童声。

**技术栈建议（实现阶段再定）：** React / Vue + 纯 Canvas 或 DOM 拖拽均可；首版 DOM + CSS 足够，矢量统一用 SVG。部署：**GitHub Pages**。

## 九、内容规格（便于量产）

每关一份 JSON 配置，例如：

```json
{
  "id": "en-letter-a",
  "stage": 1,
  "template": "fit-in",
  "target": { "glyph": "a", "audio": "a.mp3" },
  "pieces": [{ "id": "p1", "glyph": "a", "correct": true }],
  "distractors": [],
  "successAudioRepeat": 3,
  "snapDistance": 48,
  "theme": "wooden-wall"
}
```

字母关可脚本生成；汉字关维护「字表 + 音频 + 配图」。

## 十、分期规划

### Phase 1 · MVP（验证核心爽感）

- 世界地图壳 + 英文字母 a–z 嵌合关（先小写，或 a / A 分开关）
- 拖拽吸附、点击发音、三连成功音、撒花、本地进度
- 家长设置：音量、提示开关

**成功标准：** 孩子能独立完成 ≥5 关且愿意「再来一关」。

### Phase 2

- 大小写配对、字母顺序轨、听音点选
- 拼音单韵母 / 声母嵌合
- 干扰项难度档（易 / 中）

### Phase 3

- 汉字整字 + 简单部件拼
- 3–4 字母英文词拼写
- 收集墙、今日目标

### Phase 4

- 词语、跨模块复习关、账号同步、家长报告

---

## 十一、体验与安全约束

- 默认无外链广告；外链需家长锁
- 颜色对比清晰，可触控区域 ≥ 44–48px
- 动画可「减少动态」
- 文案尽量图标化；必要文字用超大字号

---

## 十二、本版策划的取舍（明确不做）

| 不做（先） | 原因 |
|------------|------|
| 真实手写笔迹批改 | 识别成本高、挫败感强 |
| 开放世界自由探索 | 分散注意力，开发量大 |
| 多人对战 | 适龄与安全风险 |
| 一次性做齐汉字全库 | 内容与音频瓶颈；先高频字 |

---

## 策划结论

系统用「嵌合拼图」做统一玩法引擎，按 **字母 → 拼音 → 汉字 → 拼写 → 词语** 进阶。

MVP 只打磨 `a` 关体验到「点声 – 拖吸 – 三连 – 撒花」闭环，再横向复制到 26 字母，是可玩性与可实现性最平衡的第一版路径。
